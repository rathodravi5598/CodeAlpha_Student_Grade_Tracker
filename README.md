# CodeAlpha_Student_Grade_Tracker
CodeAlpha_JAVA_TASK_1

-> A core Java application developed as part of the CodeAlpha Java Programming Internship to manage, compute, and track student grades efficiently.

# 📌 Project Overview

-> The **Student Grade Tracker** enables users to input student details and scores, compute performance metrics (Average, Highest, Lowest), and view a neatly formatted summary report.
-> This Is a consloe based output system.

# ✨ Features

->  **Dynamic Student Entry:** Dynamically input and store student records using Java's `ArrayList`.
->  **Automated Score Computations:** Automatically calculates
->  Average Score
->  Highest Score and Top Performing Student
->  Lowest Score and Lowest Performing Student
->  **Formatted Report Display: Presents a clean, tabulated console summary report.
->  **Input Validation: Handles buffer management and valid numeric grading.


# 🛠️ Tech Stack & Concepts Used
->  *Language: Java (JDK 8+)
->  *Concepts:** Object-Oriented Programming (OOP), Collections Framework ('ArrayList'), Control Flow, Scanner Input & Formatting (`printf`)
->  *IDE:* Eclipse IDE
